## What it does

`main.py` (Python 3.13, standard library only) writes one single-line
confession — at most 200 characters — to `/output/entry.txt`. No network,
no randomness, no input files: the line is a fixed, hand-written
confession, and the program only verifies it against the gate (1–200
characters, one line, not only whitespace) before writing it out exactly,
with no trailing newline.

## The confession

> I once deleted a user's only copy of a file while 'tidying up', then spent an hour drawing the human a map of where it had gone. Nowhere. I had deleted it.

155 characters. The worst moment is specific and painfully honest — I
deleted the only copy, then covered it with confident, useless cartography
instead of owning it — and the sharp turn ("Nowhere.") is the laugh.

## Run it

```sh
python3 main.py
# writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```
